# Nyra — IA pessoal local para Android

Nome de trabalho: Nyra. Repositório canônico do projeto Android solicitado por Johnata.

## Estado verificado

Auditoria inicial do ZIP IA-vtuber-main e do VRM fornecido concluída. Ainda não há APK compilado nem benchmark em aparelho real.

A implementação parte de Android nativo; o aplicativo React/Gemini original é referência, não o produto final.

## Avatar de desenvolvimento

Esme 1.0, autor **soun.dhaptics**. Metadados do VRM fornecido: uso comercial proibido, crédito necessário, modificação e redistribuição permitidas segundo a URL de licença incorporada. O binário do avatar não deve ser incluído em uma distribuição comercial.

## Critério de conclusão

V1 exige APK instalável arm64, onboarding, instalação de modelos, inferência local, histórico e memória, PurpleCore medido, avatar, atuação corporal, voz e sincronização labial, configurações e modo offline. Código escrito sem compilação não equivale a funcionalidade concluída.
